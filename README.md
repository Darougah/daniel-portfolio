## Implementation

The portfolio is a static `index.html` using React and Tailwind CSS loaded through browser scripts. No build step is required.

## Preview locally

```sh
python3 -m http.server 8080
```

Open http://localhost:8080. Internet access is required for the external browser dependencies and project images.

## Update content
